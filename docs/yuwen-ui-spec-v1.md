# 语文伴学 App 1.0 UI 规范（小学阶段）

## 1. UI 结构

### 1.1 信息架构（移动端）
- 一级导航：`首页` / `学习` / `复习` / `家长`
- 二级关键流：
  - 首页 -> 开始学习 -> 学习会话（卡片流）
  - 首页 -> 继续上次 -> 学习会话（断点恢复）
  - 复习 -> 今日待复习 -> 单题复习流 -> 结果反馈

### 1.2 学习会话结构（每屏一任务）
1. 导学卡（目标+暖场）
2. 字词卡（6-10 个）
3. 精读卡（段落级理解）
4. 主旨卡（结构+一句话主旨）
5. 小测卡（单题）
6. 反馈卡（证据句+温和纠错）
7. 收尾卡（掌握点+明日复习）

---

## 2. 设计系统

### 2.1 色彩系统（克制童趣 + 高级感）

#### 核心颜色
- `Primary-500`：`#3C8DFF`（柔和学习蓝）
- `Primary-100`：`#EAF3FF`（蓝色浅底）
- `Mint-500`：`#2FB8A8`（青绿辅助）
- `Accent-500`：`#FFB44D`（鼓励/奖励）
- `Accent-100`：`#FFF4E5`（奖励底色）

#### 中性色
- `Bg-Base`：`#F7F8FA`（页面背景）
- `Bg-Card`：`#FFFFFF`（卡片背景）
- `Border-Light`：`#E8ECF1`
- `Text-Primary`：`#1F2937`
- `Text-Secondary`：`#5B6473`
- `Text-Tertiary`：`#8B93A1`

#### 状态色
- `Success`：`#34B27B`
- `Warning`：`#F5A524`
- `Error`：`#E66A6A`
- `Info`：`#4E8DF5`

### 2.2 字体系统
- 中文优先：`PingFang SC`（iOS）/ `Noto Sans SC`（Android）
- 英文与数字：`SF Pro Text` / `Inter`（仅系统回退）

#### 字号层级
- `H1`：28/36，600，页面主标题
- `H2`：22/30，600，模块标题
- `Title`：18/26，600，卡片标题
- `Body`：16/24，400，正文
- `Caption`：13/18，400，辅助说明
- `Meta`：12/16，500，标签/状态

### 2.3 间距与圆角
- 8pt 栅格：`4 / 8 / 12 / 16 / 20 / 24 / 32`
- 卡片间距：16
- 页面左右边距：20
- 圆角：
  - 小组件：12
  - 卡片：16
  - 主按钮：18
  - 全宽浮层：20

### 2.4 阴影与层级
- 卡片阴影（浅）：`y=4 blur=16 rgba(31,41,55,0.06)`
- 弹层阴影（中）：`y=10 blur=24 rgba(31,41,55,0.10)`
- 不使用重阴影和高对比描边，保持轻盈。

### 2.5 动效规范（克制）
- 页面切入：`fade + translateY(8->0)`，220ms，ease-out
- 卡片切换：`slideX + fade`，240ms
- 点击反馈：按钮 `scale 1 -> 0.98 -> 1`，120ms
- 错误提示：仅轻震动 + 文案淡入，不做强烈抖动

## 3. 组件定义

### 3.1 Button（大点击区）
- 高度：`52`
- 最小点击区：`52 x 52`
- 类型：
  - `Primary`：主流程（开始学习、下一步）
  - `Secondary`：次流程（再看一遍）
  - `Ghost`：弱操作（稍后）
- 文案语气：鼓励式，如“继续努力，再试一次”

### 3.2 Card
- 默认圆角：16
- 内边距：16
- 结构：`标题` + `正文/内容区` + `操作区`
- 使用场景：学习卡、复习项、进度摘要

### 3.3 Progress
- 顶部细进度条 + 文本（例：`第 3 / 7 步`）
- 高度：6，圆角胶囊
- 当前进度色：Primary-500，底色 Primary-100

### 3.4 Feedback Box（温和纠错）
- 正确：浅绿底 + 对勾图标 + 正向肯定
- 错误：浅橙底 + 灯泡图标 + “提示你如何找依据”
- 固定区块：`为什么错` / `文中依据句` / `再练一题`

### 3.5 Chip
- 用途：标签、skillTag、状态
- 高度：28，左右内边距 10
- 风格：浅底色 + 中性色文字，不做高饱和实心块

### 3.6 Bottom Tab
- 高度：80（含安全区）
- 图标线性、具象
- 激活态：主色 + 文字 600
- 未激活：Text-Tertiary

## 4. 页面布局

## 4.1 首页（Home）
- 顶部：问候 + 今日日期 + 学习连续天数
- 主卡（最大权重）：
  - 今日推荐课文
  - 预计 10 分钟
  - 主按钮“开始今天学习”
- 次卡：
  - 继续上次（仅未完成时）
  - 待复习（最多 3 条）
  - 本周进度（完成课次 + 能力标签）
- 布局原则：同屏不超过 4 个信息块，避免拥挤

## 4.2 学习页（Session）
- 头部：
  - 返回
  - 进度（第 x / y 步）
  - 课文标题
- 主区：单张任务卡（全屏视觉中心）
- 底部：主操作按钮（下一步/提交）
- 卡片行为：
  - 只展示一个任务
  - 提交后即时反馈
  - 反馈后自动聚焦“下一步”

## 4.3 复习页（Review）
- 顶部切换：`今日待复习` / `已完成`
- 列表项信息：
  - 类型（字词/证据句/主旨/背诵）
  - 难度标记
  - 到期时间（今天/明天）
- 主要交互：
  - 一键开始今日复习
  - 单项进入快速复习

## 5. 统一视觉语言

### 5.1 图形与插画
- 使用轻量几何图形和单色线稿插画
- 插画只用于空状态、成功反馈、奖励节点
- 避免复杂大场景卡通和高细节人物插图

### 5.2 图标风格
- 线性图标（2px），圆角端点
- 图标语义具象：书本、放大镜、奖章、喇叭、闹钟

### 5.3 文案语气
- 鼓励式、非命令式：
  - “你已经掌握得很不错了”
  - “我们再找一句依据试试”
- 避免“错误”“失败”硬提示，用“再试一次”替代

---

## 6. 细节优化（交互反馈）

### 6.1 触控与误触控制
- 所有主要点击区 >= 44px
- 危险操作（二次确认）：删除数据、撤回同意

### 6.2 状态覆盖
- 每页必须支持：`loading / empty / error / offline`
- 错误状态提供明确下一步：重试、返回首页、联系客服

### 6.3 可访问性
- 字体支持系统放大
- 颜色对比度满足正文可读性（AA）
- 音频播放按钮有文本标签

### 6.4 反馈节奏
- 提交后 300ms 内出现反馈占位
- 2s 内返回判题结果
- 成功后使用轻动效（对勾浮现），不超过 600ms

---

## 7. 交付给开发的落地要点

- 先实现设计 Token（颜色、字体、间距、圆角、阴影、动效时长）。
- 组件优先级：`Button -> Card -> Progress -> FeedbackBox -> Chip -> TabBar`。
- 页面优先级：`学习页 -> 首页 -> 复习页`。
- UI 验收标准：
  - 每屏只做一件事
  - 视觉元素不超过 3 层主次
  - 关键路径（开始学习到提交）不超过 2 次跳转
