# UI Rules

## Visual Style
- Clean, premium, modern SaaS aesthetic
- Generous whitespace
- Minimal color palette
- Subtle borders over heavy shadows
- Consistent 8px spacing system

## Components
- Buttons must use one shared pattern
- Inputs, selects, and modals must feel like one system
- Avoid multiple competing card styles

## UX
- Every async action needs loading feedback
- Every list needs empty state
- Every form needs error states
- Mobile responsiveness is required

## Avoid
- Loud gradients
- Inconsistent border radius
- Random one-off font sizes
- Over-animated interactions
